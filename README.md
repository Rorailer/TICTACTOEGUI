# Tic Tac Toe GUI

This repository contains a **Graphical User Interface (GUI)** implementation of the classic Tic Tac Toe game written in **C++**. It provides an interactive and visually appealing way to play the game, offering a user-friendly experience.

## Features

- Interactive GUI for Tic Tac Toe.
- Support for two players.
- Highlights winning moves.
- Reset functionality for restarting the game.
- Clean and minimalistic design.

---

## Requirements

To run this project, you need:

1. A C++ compiler supporting **C++11** or later.
2. A GUI library such as **Qt**, **SFML**, or any other framework used in this project.
3. [CMake](https://cmake.org/) (if a build system is used).
